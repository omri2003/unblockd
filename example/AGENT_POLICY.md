# Agent policy (example)

How agents do the work on THIS project. The claim / heartbeat / complete protocol is built in
(unblockd/WORK_LOOP.md) and cannot be changed here. Edit everything below to fit your project.

- Before `complete`: run the tests (`python -m unittest`) and say what you did NOT verify.
- Commits: one per ticket, message starts with the ticket id (`API-2: ...`). Never push to `main`; open a PR.
- Ask a human (`ask_human`) before: deleting data, changing a public API, adding a dependency.
- Summary language: English, plain, cause -> fix -> tests.
