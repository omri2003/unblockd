# Ticket store
One JSON file per ticket in `tickets/`, committed with the code it describes. Owns validation, ids and derived fields (`effective_status`, `blocks`), which are computed on read and never written.

## Connections
- [docs](docs.md) — the ticket field table in `docs/guide.md` is generated by hand from the schema: a new or renamed field means updating that table in the same commit
