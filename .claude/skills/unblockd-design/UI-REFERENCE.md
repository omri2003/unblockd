Bullet names are unchanged, so `[AGENTS: "<bullet>"]` tags in SKILL.md find them here. Load this file (with SKILL.md) before designing or reviewing any change to static/index.html.

## From "How the pieces work"

### Boards

UI: board in `?board=` + localStorage. Switcher = page title: `#bpanel` (`.spanel` `<details>`, `<summary>` = h1 + chevron, in `MENUS`), list built by `paintBoards()` into `#bbody` from `BOARDS` (`loadBoards()` fetches once per page; also feeds chat `@board` completion and `#board/ID` refs; no `<select>`). One board: `#bsum` `inert` (plain title, no chevron). `Shift+B` opens, arrows/Enter pick, Esc closes. `b` reserved for planned add-blocker shortcut (UI-8).
**View switch** Board | Graph | Docs | Map | Roadmap = `#viewSeg` (`.vico-g`, built by `paintViews(v)`) in `.trow` after title; independent of `#bpanel` (icon click never opens board menu; shown with one board too). 16px stroke SVGs (`VICON`); active = icon + label, others icon-only (owner decision 2026-10-24, UI-52: compact wins; names in tooltips): `title` `Graph (g)` / `Docs (d)` / `Map (m)` / `Roadmap (r)` + `aria-label`, `aria-pressed`; buttons keep `data-view` (`ui_smoke.mjs` clicks it). Right cluster = actions only (Ask Claude = chat, New ticket, Agents, ⚙, ?). Header tooltips carry their key (`New ticket (n)`, `Graph (g)`...); `?` (tooltip `Shortcuts (?)`) opens the `?` sheet: new shortcut updates sheet AND tooltip. **Header** = ONE row: `.trow` = logo, `#bpanel`, `#viewSeg`, `#needsBadge`; `.hdr` = actions; wraps only at <=600px. No subtitle (`#sub`), no "Press ? for shortcuts" link, no status strip: counts live in column heads; `renderAgBtn` (called by `render`) labels `#agBtn` `Agents · N live` (plain `Agents` at 0).

Sections ticket picked of one doc = ONE card (`dRows`: name + chip per section, jade sent / cinnabar not, `N of M sections sent`). Under doc's last card row fold (`dSecHtml` / `dSecState`, open state `dSecOpen`) opens three ways (UI-72, owner pick "middle ground" of 3 options in 3 situations): doc not sent in full with headings has strip **Didn't fit. Send only the parts this ticket needs.** + **Pick sections** (`.dsec.miss`, summary); with no headings strip (`.dstrip`) says there is nothing to pick: split doc or raise budget; doc sent in full with 2+ headings (UI-75, owner 2026-11-16: any size; UI-72 did it only past third of budget, `knowledge.BIG_SHARE`) gets quiet **Sections** button in its card head (`dSecBtn`, `data-dsecopen`, `aria-expanded`) that opens same fold, using outline `knowledge.preview_outlines` adds for REST preview only to sent doc with >= 2 headings (`context?content=0`; agents never get outline on sent doc; doc with 0-1 headings gets no button); once sections are picked summary reads **Change sections**. ## Conventions (UI)

- **One-file UI**: vanilla JS in `static/index.html`. Colours = CSS tokens on `:root`, each `light-dark(light, dark)` with `color-scheme: light dark`: no separate dark block; add token once with both values. Pillar colours are generated into same form from config (`color`, `color_dark`) in `applyConfig`.
  **Elevated look** (owner trial 2026-11-10 on branch `dev/premium-look`, after reference dashboard): neutral grey `--paper`, white `--surface`, hairline `--line`; depth from three shadow tokens `--sh1` (resting: cards, buttons, inputs, count pills) / `--sh2` (hover; cards lift 1px) / `--sh3` (popovers, drawer, palette), colours `--shc` / `--shc2` = `light-dark()` so dark mode gets deeper shadows. Radii `--r` 8px (controls), `--rc` 12px (cards, panels), column trays 14px. Segmented controls = `--sunk` track + raised white pill (`.vico` sets `--ind:var(--surface)`); column heads = status dot + count pill, no underline; `.btn.ghost` white with ink text. Overrides in ONE block (`/* Elevated surfaces ... */`) right before motion rules. Use shadow tokens, never raw `rgba` shadow, on new surfaces.
  **Design pass 2** (2026-11-10, ranked top 10 of 9-agent design debate; block `/* Design pass 2` after Elevated block): cards title-first (ID small + muted; P0 keeps wash + seal + cinnabar ID; stale card shows only `No update for N days`, not age too); pillar spine = floating 3px capsule (`.card::before`, `--pc`), not border (border bends around radius); card owner = byline (glyph + name, muted for agents, ink bold for people; drawer keeps pill); card head never wraps; dark mode: lighter surfaces + top-edge highlight `--hl` inside every shadow token; fonts Segoe UI Variable on Windows / SF on Mac (still system fonts); only objects float (header actions other than New ticket = flat toolbar buttons, quick-add = dashed slot until focused, blocked cards lie flat, open ticket's card has soft ring); drawer status = same grey track + raised pill as `#viewSeg`, with status dot; buttons and cards press in (`:active`, 80 ms); drawer / popovers arrive (200 / 150 ms; JS-positioned `.fbody` only fades and drops: open handler measures it, so it must not be scaled); live claim's dot ripples (`.liv .pulse::after`, endless, compositor-only), not blinks. Hover lift, shadow transitions and all of Design pass 2 motion are off under reduced motion.
- **Settings** (⚙ in header, `#spanel`), per browser, `store` keys: `theme` (system|light|dark), `density` (comfortable|compact), `digest` (on|off), `tags` (off|on, default off: card's `#tags` and `→ agent` hint; UI-46; drawer always shows them), `me` ("I am": human owner name or ''). `SET` / `setPref(k,v)` / `renderSettings()`; buttons carry `data-pref="k:v"`. Theme = `data-theme` on `<html>` (unset = System) picking `color-scheme` in three tiny rules; Density = class `compact` on `<html>` (few `.compact` rules after `:root`). A tiny inline `<script>` in `<head>` applies both before first paint (no flash). `t` cycles theme. **A custom property holding `light-dark()` reads back unresolved**, so JS needing real colours (`readColors()` for graph canvas and grain) resolves them through hidden probe element's `color`; `setPref('theme')` and OS `matchMedia` change both call `readColors(); kick()`. Never read token with `getPropertyValue` for drawing; never `closest('[data-theme]')` (`<html>` carries it).
- **Show mode** (`showSet` in index.html): M = `matches()`; Only = M, Paths = M + ancestors + descendants over visible universe (two separate walks), Dim = all. Per view (`showModeBoard` / `showModeGraph`). Board uses `BV` (set in `render()`); graph filters in `syncGraph()` before edges/layout, so Flow re-lays out subset.
  **Graph toolbar** (UI-50): Flow/Free, Linked tickets only, Show done (`gDone`, default OFF: done tickets were most of big board's dots), More (`#gmore`, `.spanel` popover in `MENUS`: Mentions in details, Critical path, Isolate on click), Fit to view; > 80 nodes drawn → faint links (`calm`) until ticket is focused. **Isolate on click** (`gIsolate`, default on), separate from Show mode: `G.isolate = id` (not persisted) makes `syncGraph()` skip `showSet`, filters and "Linked only" and draw `withChains(T,{id})` (ancestors + descendants over all of T; done only if Show done; root always). `G.focus` pinned to it (`setFocus(null)` re-focuses root); leave with `leaveIsolate()` (Esc, empty canvas, Back to all, board view, unticking box), restoring zoom/pan in Flow. Don't reuse `state.q`/`showGraph` for it.
  Search `/re/` parsed once in `setQ()`; tested against `id title` and `id` alone, so `/^BUG-10$/` works.
- **Priority** (`PDEF`/`PLAB` in index.html = ONE source for definitions: P0 breaks things or blocks people now, P1 must happen for goal, P2 should happen, P3 nice to have, none counts like P3): read by edit/new form's select (full width, so text is not clipped), bulk bar's select and the `?` sheet (`#kbPrio`). **`p` then `0`-`3` / `-`** (`startP`/`endP`/`setPrio`, state `PK`): target = open drawer's ticket, else focused `[data-open]` card; `p` alone shows toast-styled hint for 1.5 s, any next key or Esc ends it; PATCH toast has Undo; focused card is re-focused after update so `p 0` then `p -` chains. Drawer draft keys `dn:`/`da:` + `board/ID`, like panel's. Taken keys, do not reuse: `i` = Needs you, `b`/`B` = see Boards, `l` = Board Columns | List.
- **View in the URL** (`urlWrite()` in `render()` and `setView`; `urlRead()` once at init after `applyConfig`): params `view` (board|graph|docs|map|roadmap) `q pillar owner agent parent comp milestone priority(comma) me(=1) show group layout(=list, board view only) dep`, non-default only, `history.replaceState` keeping `?board=` and `#ID`; `show` = current view's Show mode, `dep` only in Graph. Any of them in URL defines whole view (rest = defaults, localStorage ignored); values validated with `pickOf`. A new filter needs param here.
  Board switch (`switchBoard(v)`, UI-74) stays in page and resets exactly what reload of `?board=` did (filters drop same way): `history.pushState` `?board=<v>` with no view params (urlRead finds none, remembered choices apply); Back / Forward = `popstate` → `switchBoard(v, false)` (entry without `?board=` = board page opened on, `BOARD0`). Old-board requests never settle: `rawFetch` drops any answer arriving after `BGEN` moved (body read in wrapper). A new per-board variable must be reset there too. Failed `meta` → old full navigation; New board still reloads (needs new list).

Self-declared, per browser: label, not identity. No shortcut key. UI PATCH / DELETE still send no name.
